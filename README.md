# OtcSensConvert - Release

Eseguibili di **OtcSensConvert**, convertitore per programmi OTC Almega AX con touch sensing.
Questo repository contiene solo i binari (Release); il sorgente e' privato.

## Installazione

1. Installa il **.NET 8 Desktop Runtime** (x64) se non e' gia' presente.
2. Scarica `OtcSensConvert.zip` dall'ultima [Release](../../releases/latest) e decomprimilo in una cartella a tua scelta.
3. Avvia `OtcSensConvertGui.exe` (interfaccia grafica). `OtcSensConvert.exe` e' la versione da riga di comando.

L'app controlla da sola gli aggiornamenti (disattivabili dalle impostazioni): scarica solo da questo repository e verifica lo SHA-256 prima di installare.
Lo SHA-256 dello zip e' pubblicato anche nel file `OtcSensConvert.zip.sha256` di ogni Release.
